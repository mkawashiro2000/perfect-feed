Node Exporter existe para traducir los datos de la máquina operativa (CPU, memoria, disco, red) a un formato que Prometheus puede entender. No es un herramienta de monitoreo por sí misma, sino una simple translator que responde a solicitudes HTTP en el puerto 9100 con los datos actuales de la máquina. Prometheus y Node Exporter son dos herramientas separadas: Prometheus no sabe nada sobre CPUs ni memoria, pero puede "preguntar" a cada objetivo qué datos quiere recopilar. Grafana, por otro lado, es una herramienta que pregunta a Prometheus para obtener respuestas en forma de gráficos, pero no almacena métricas por sí misma. Una vez que se comprende el modelo, instalar estas piezas es un proceso mecánico: simplemente configurar cada enlace en la cadena. Para instalar Prometheus, se puede descargar desde su sitio oficial y ejecutar el comando `prometheus --config .file=prometheus.yml` para iniciar el servicio. Node Exporter se puede instalar de manera similar, descargando su versión oficial y ejecutando el comando correspondiente para iniciar el servicio. Grafana también se puede instalar desde su sitio oficial, pero requiere que Prometheus esté configurado y funcionando correctamente.
